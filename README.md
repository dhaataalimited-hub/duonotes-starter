# DuoNotes starter

Your phone as a folder in your repo. This template gives you a ready-made repo for DuoNotes: a guide, a few small
games, and an inbox for what you capture.

## Set up (about five minutes)
1. Tap **Use this template › Create a new repository** (top of this page). Make it **Private**: it's your notes.
2. In DuoNotes, tap **From GitHub**, sign in, and choose your new repository when GitHub asks which ones DuoNotes may
   use.
3. Pick **inbox** and tap **Add**. Do the same for **guide** (the lessons) and **play** (the games) if you like.
4. Dictate a note in Inbox. It appears in `inbox/` here within a minute.

## What's inside
| Folder | What it is |
|---|---|
| `inbox/` | Where your notes go. Start here. |
| `guide/` | Short lessons: dictation, checklists, code, and file types DuoNotes can show (HTML, CSV, Mermaid, JSON, SVG). |
| `play/` | Five small HTML games that save your progress beside them. |
| `links/` | Save links here; ask an AI agent to "check links" and it writes back what each one is, with tags. |
| `AGENTS.md` | Rules for AI agents (Claude, Codex, ChatGPT…) writing to your repo. Point your agent at it. |

Your copy is yours: changes you make never touch this template.
