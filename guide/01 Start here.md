# 01 · Start here

Welcome to DuoNotes! Your notes live on your iPhone and can sync with a connected folder on GitHub (a place where files and their changes are stored). **Your phone is a folder in your repo** is our shorthand for that connection.

This `guide/` folder came from GitHub: an AI agent added the files, and DuoNotes downloaded them to your phone.

## What you can do
- **Capture:** dictate, write, or scan a note on your phone. DuoNotes syncs it to GitHub.
- **Receive:** an AI agent can add notes, tables, diagrams, or small web tools to a linked folder; they appear on your phone.
- **Respond:** edit a note, tick a checklist, or leave a sticky note; your changes sync back.

## How this folder got here
In DuoNotes, **From GitHub** (beside New Folder) lets you pick a repository and one of its folders; DuoNotes makes a matching folder and brings its files down. **Link to GitHub…** on an existing folder does the same for a folder you already have. Either way, DuoNotes says what will move before anything does.

Work through the numbered examples in order. Lessons 01–03 and 11 are the beginner path; 04–10 show additional file formats and tools.

**Sync tip:** long-press this folder for **Sync Now**, or pull down on the list. While the app is open, GitHub changes usually arrive within about a minute. If something doesn't appear, check that it was added to a folder linked in DuoNotes (such as `guide/` or `inbox/` in this example).
