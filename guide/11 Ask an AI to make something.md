# 11 · Ask an AI to make something

You can use DuoNotes to exchange work with an AI assistant. The AI creates a note in a connected GitHub folder, you use it on your phone, and your edits can sync back.

## Try the complete loop

1. Open an AI assistant that has permission to access this GitHub repository.
2. Ask it: **“Create a simple weekend shopping checklist as a Markdown file in the linked `inbox/` folder. Don't overwrite any existing notes.”**
3. Open DuoNotes and find the linked **inbox** folder. Pull down to refresh or use **Sync Now**. The new checklist should appear after syncing.
4. Tick one item, or dictate an extra item into the note, and save it.
5. Ask the AI: **“Read the shopping checklist from GitHub and tell me which items are complete.”**

## What just happened?
- **AI → GitHub → phone:** the assistant created a file you could use on your iPhone.
- **Phone → GitHub → AI:** your edits became available for the assistant to read.

## If it doesn't appear
- Confirm the AI wrote the file inside the folder linked in DuoNotes, not the repository root.
- Check that you're viewing the right linked folder and branch.
- Refresh the folder while DuoNotes is open.
- A GitHub commit means the file was saved to GitHub; it doesn't by itself prove the phone has received it.

**Optional next challenge:** ask the AI to make a weekly plan, then tell it what you changed on the phone.

**Privacy tip:** don't put passwords, tokens, or other secrets in notes you share through GitHub.
