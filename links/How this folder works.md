# How this folder works

Drop links here: share or paste a link into a new note in **Links** (add a few words on why, if you like).

An AI agent (Claude, ChatGPT, Codex…) then looks each one up and writes back into the same note:
what it is, who made it, tags and a category. Pull down to see it arrive.

The rules agents follow are in `AGENTS.md` › "Folders with a job: `links/`".
